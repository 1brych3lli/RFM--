# RFM-анализ клиентов — сегментация для маркетинга

## 📌 О проекте

Скрипт анализирует историю покупок клиентов и автоматически сегментирует их по ценности для бизнеса по методике RFM. Результат — готовый HTML-отчёт с графиками, таблицами и маркетинговыми рекомендациями.

**Цель:** помочь маркетологам и менеджерам понять, кто из клиентов:
- приносит максимальную прибыль (VIP)
- находится под угрозой ухода
- давно не покупал (спящие)
- только начал покупать (новые)

---

## 📊 Что такое RFM-анализ

RFM — это метод оценки клиентов по трём параметрам:

| Параметр | Что значит | Почему важно |
|----------|------------|---------------|
| **Recency** (давность) | Как давно клиент совершил последнюю покупку | Недавние клиенты с большей вероятностью купят снова |
| **Frequency** (частота) | Как часто клиент покупает | Частые покупатели — самые лояльные |
| **Monetary** (сумма) | Сколько всего потратил клиент | Большие траты = высокая ценность |

---

## 📁 Что нужно на входе

Excel-файл с колонками (названия могут быть любыми — скрипт определит сам):

- **Клиент** — имя, ID, email, номер телефона (любой идентификатор)
- **Дата покупки** — дата в любом формате
- **Сумма покупки** — число (можно с копейками)

---

## 📈 Что вы получаете на выходе

Скрипт создаёт один **HTML-файл**, в котором есть:

### 1. Общая статистика
- Всего транзакций
- Уникальных клиентов
- Общая выручка
- Средний чек

### 2. Два интерактивных графика
- **Круговая диаграмма** — распределение клиентов по сегментам
- **Столбчатая диаграмма** — выручка по сегментам

### 3. Таблица сегментов

| Сегмент | Клиентов | Доля | Визуальный индикатор |
|---------|----------|------|----------------------|
| VIP клиент | 8 | 32% | 🟢 Зелёный |
| Лояльный | 3 | 12% | 🔵 Синий |
| Новый | 1 | 4% | 🔷 Бирюзовый |
| Риск ухода | 2 | 8% | 🟠 Оранжевый |
| Спящий | 10 | 40% | ⚪ Серый |
| Обычный | 1 | 4% | 🟣 Фиолетовый |

### 4. Таблица клиентов (первые 50)
Для каждого клиента показывает:
- Имя/ID клиента
- Давность последней покупки (дней)
- Частота покупок
- Общая сумма
- RFM-оценки (Recency / Frequency / Monetary)
- Итоговый сегмент

### 5. Рекомендации по каждому сегменту

| Сегмент | Рекомендация |
|---------|---------------|
| 🔥 VIP | Удерживать персональным менеджером, давать эксклюзивные условия |
| 💚 Лояльные | Развивать через кросс-продажи, программы лояльности |
| ✨ Новые | Вовлекать welcome-бонусом, знакомить с ассортиментом |
| ⚠️ Риск ухода | Активировать срочной скидкой или персональным предложением |
| 💤 Спящие | Возвращать reactivation-кампанией (письмо/смс со скидкой) |
| 📌 Обычные | Постепенно повышать частоту покупок через триггерные рассылки |

---

## ⚙️ Как это работает (без кода)

1. Скрипт читает Excel-файл с историей покупок
2. Автоматически определяет колонки с клиентом, датой и суммой
3. Рассчитывает RFM-метрики для каждого клиента
4. Присваивает оценки (от 1 до 4) по каждому параметру
5. Определяет сегмент по комбинации оценок
6. Генерирует HTML-отчёт с графиками, таблицами и рекомендациями
